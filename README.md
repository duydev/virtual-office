# Văn phòng ảo 3D

Web 3D mô phỏng văn phòng ảo, xây dựng bằng Vite + React + TypeScript + Three.js (React Three Fiber, drei).

## Chạy local

```bash
npm install
npm run dev
```

Mở http://localhost:5173

## Điều khiển

- WASD / phím mũi tên: di chuyển, Shift: chạy
- Kéo chuột: xoay camera, cuộn chuột: zoom
- E: tương tác khi đứng gần đồ vật
- N: ngày/đêm, C: đổi camera, H: ẩn/hiện hướng dẫn
